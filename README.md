# dsh-seasonal-theme · 四季主题

给 DeepSeek Harness 的一套四季渐变主题插件：左侧栏进入主题工作室，一键切换春、夏、秋、冬四套配色，也可以让它随月份自动换季。

浅色和深色外观都做了完整适配，切换后整个 Web 界面（对话区、左侧栏、标题栏、气泡、菜单、代码块）一起变。

## 四季

| 季节 | 名称 | 月份 | 主色 |
|---|---|---|---|
| 春 | 春 · 初樱 | 3–5 月 | 樱粉 `#fbc6dd` |
| 夏 | 夏 · 青岚 | 6–8 月 | 青蓝 `#abe2ec` |
| 秋 | 秋 · 金桂 | 9–11 月 | 琥珀 `#fabd89` |
| 冬 | 冬 · 霜蓝 | 12–2 月 | 霜蓝 `#bfcef8` |

（表中为浅色外观下对话区的实际叠色。）

## 安装

在 DeepSeek Harness 里让它自己装：

```
安装 dsh-seasonal-theme 这个插件
```

或者手动：

```bash
dsh plugin --profile <你的 profile 名> add dsh-seasonal-theme
```

从 GitHub 直接装：

```bash
dsh plugin --profile <你的 profile 名> add github:<owner>/dsh-seasonal-theme
```

装好后重启或刷新页面，左侧栏会出现「四季主题」入口。

## 使用

1. 点左侧栏的「四季主题」。
2. 点任意季节卡片，立即应用。
3. 「跟随四季」开关打开时按月份自动切换；手动选了某个季节后回到手动模式。
4. 底部「恢复 DSH 原色」可以随时退回默认配色。

选择保存在当前浏览器里，换浏览器或清缓存会回到自动模式。

## 说明

- 纯前端：只覆盖主题 token 和背景渐变，不联网、不上传数据、不注册工具。
- 切换季节只改配色，不动你的其他设置；卸载后配色自动还原。
- 四季页和对话区共用同一层背景渐变，所以在主题页看到的颜色和对话区一致。
